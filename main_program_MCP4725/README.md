Модифицированная пятая версия многостадийного терморегулятора и ЦАП в одной программе. Предназначена для многоэтапного 
управления температурой при помощи ПИД-регулятора и напряжением с помощью модуля MCP4725.
Считывание температур происходит последовательно на шине SPI при помощи сдвиговых регистров с 25 термопар.
Считывание токов происходит последовательно на шине I2C при помощи сдвоенного мультиплексора 4 в 1.

Предшественником является программа MultiStageDACandPIDoperation_5_16ina_mux_25max.

Пины подключения на схеме и в проге можно посмотреть MultiStageDACandPIDoperation_5.
