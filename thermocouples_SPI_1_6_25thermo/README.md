Программа для работы с набором термопар (без программ Command_Analyzer и Command_Parser). 
Предназначена для управления большим количеством термопар с использованием сдвигого регистра 74HC595. Для считывания температур используются термопары MAX6675.

Что поменялось?
По сравнению с предыдущей версией протестирован вариант работы не с 8 термопарами, а с 25, как должно быть в итоговой проге.

Команды для управления:
writeByteToReg; - выставление определенной байта на выходе с регистра
readOnePointOnce; - считывание температуры с одной термопары один раз и вывод в порт
readOnePoint; - считывание температуры с одной термопары до прерывания и вывод в порт
readAllTempOnce; - считывание температур со всех термопар один раз и вывод в порт
readAllTemp; - считывание температур со всех термопар до прерывания и вывод в порт
stop_reading; - остановка считывания
