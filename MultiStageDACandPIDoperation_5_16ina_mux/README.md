Модифицированная пятая версия многостадийного терморегулятора и ЦАП в одной программе. Предназначена для многоэтапного 
управления температурой при помощи ПИД-регулятора и напряжением с помощью модуля MCP4725.
Предшественниками являются программы MultiStageDACandPIDoperation_5 и INA219_3_16ina_mux4to1.
Считывание токов происходит последовательно на шине I2C при помощи сдвоенного мультиплексора 4 в 1.

Пины подключения на схеме и в проге можно посмотреть MultiStageDACandPIDoperation_5.

Что добавлено/переделано?
1. Файлы current_sensors, ina219_driver и MUX4to1 были взяты из INA219_3_16ina_mux4to1 для работы с массивом из 16 сенсоров с переключениями канала мультиплексора.
2. Были заменены файлы System_State для блокировки команд во время исполнения. (С блокировкой команд тому же устройству)
3. Файл Command_Analyzer был переделан с учетом новых файлов System_State
4. Класс INA219_dop переименован и заменен на INA219controller
5. В файл project_config.h добавлены настройки для всех сенсоров
6. В файлах Thermodat и MultiStagePIDController.h, а также в main_for_INA219 и MultiStageDAC.h функция INA219controller::readINAcurrent заменена на функцию INA219controller::readCurrentArray для чтения данных с 16 сенсоров.
Буфер current_buffer перестал использовать.
