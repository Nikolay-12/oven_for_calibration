// По сравнению с предыдущей версией MultiStageThermoregulator_5:

Переписана функция readTemperature() для считывания показаний не с одной термопары, используя библиотеку GyverMAX6675.h, а с массива из 8-и термопар с усреднением и возвратом усредненного значения.

Добавлены команды:
thermreg:readAllTemp; - считывание массива температур и среднего значения
thermreg:readAvrTemp; - считывание средней температуры с массива
thermreg:stopTempsReading; - останавливает считывание (не используется)
