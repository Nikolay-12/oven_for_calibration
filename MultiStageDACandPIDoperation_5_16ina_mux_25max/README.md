Модифицированная пятая версия многостадийного терморегулятора и ЦАП в одной программе. Предназначена для многоэтапного 
управления температурой при помощи ПИД-регулятора и напряжением с помощью модуля MCP4725.
Считывание температур происходит последовательно на шине SPI при помощи сдвиговых регистров с 25 термопар.
Считывание токов происходит последовательно на шине I2C при помощи сдвоенного мультиплексора 4 в 1.

Предшественниками является программы MultiStageDACandPIDoperation_5_16ina_mux и MultiStageThermoregulator_7_25MAX6675.

Пины подключения на схеме и в проге можно посмотреть MultiStageDACandPIDoperation_5.

Что добавлено/переделано?
1. Файл 74HC595_register_and_MAX6675_thermocouple заменен на 74HC595_register (работа с классом, а не с пространством имен, чтоб создавать экземпляры класса для термопар и для ЦАП в дальнейшем) и MAX6675_thermocouple
2. Добавлены/переделаны предыдущие команды термопарам (индивидуальное управление)
3. В многостадийные процессы терморегулирования и управления напряжением ЦАПом включены измерения с 25 термопар и 16 сенсоров.
4. Добавлено освобождение системы после "стандартного" (без прерывания) завершения измерений.
5. Добавлена функция изменения калибровки сенсоров INA219 при изменении режима измерений (I(T) и I(V))

Добавлены команды:
MAX6675:startTempReading; - запуск чтения с термопар
MAX6675:stopTempReading; - остановка чтения с термопар
MAX6675:readAvrTemp; - чтения средней температуры со всех термопар
MAX6675:readAllTemp; - чтения температур со всех термопар
