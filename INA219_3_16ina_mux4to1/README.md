Третья версия управления массивом сенсоров INA219 (с использованием программ Command_Parser_2.h и Command_Analyzer.h).
Предшественником является программа INA219_2.

Что добавлено?
1. Переделано считывание, теперь можно измерять с 16 сенсорах с переключением между четырьмя каналами мультиплексора (на каждом канале по 4 сенсора).
2. Добавлены функции с полным описанием инициализации и вывода для каждого сенсора (для дальнейшей отладки)
3. Добавлен файл MUX4to1 для управления мультиплексором.
