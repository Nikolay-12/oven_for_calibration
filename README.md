# Main programs
Arduino sketches:

INA219_3_16ina_mux4to1 - program for working with an array of INA219 current sensors (16)

MultiStageDACandPIDoperation_5_16ina_mux - program for working with a multi-stage PID&DAC controller and an array of INA219 current sensors (16); DAC -> MCP4725

MultiStageDACandPIDoperation_5_16ina_mux_25max - program for working with a multi-stage PID&DAC controller and an array of INA219 current sensors (16) and MAX65675 thermocouples (25); DAC -> MCP4725

MultiStageDACoperation_MCP4725_4 - program for working with a multi-stage DAC controller and one INA219 current sensor; DAC -> MCP4725
MultiStageThermoregulator_6_8MAX6675 - program for working with a multi-stage PID controller, one INA219 current sensor and an array of MAX65675 thermocouples (8)
MultiStageThermoregulator_7_25MAX6675 - program for working with a multi-stage PID controller, one INA219 current sensor and an array of MAX65675 thermocouples (25)
MultiStageThermoregulator_simulation_6 - program for working with a multi-stage PID controller (only simulation)
main_program_DAC0808 - pre-final assembly of the program; DAC -> DAC0808
main_program_MCP4725 - pre-final assembly of the program; DAC -> MCP4725
main_program_MCP4725_with_py_en - Pre-final assembly of a program for working with Python; DAC -> MCP4725
thermocouples_SPI_1_6_25thermo - program for working with an array of MAX65675 thermocouples (25)

Python project (user interface):
oven_python_project_3 - a graphical user interface for working with oven
